Docryvia v0.7.0-rc2

Published by choicematrix. Support: help@choicematrix.in

This release adds compatibility with modified rc2 password history and question-recovery kits, live authenticator codes on login cards, masked history with reveal controls, passphrase formatting options and confirmed empty-trash controls. It retains the secure document viewer, imports, configurable locking and autofill improvements from v0.7.
